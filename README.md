# Lintweak website

Personal site for **[Lintweak](https://codeberg.org/ualinuxoid/lintweak)** — simple Linux tweaks and privacy tools written in pure bash.

**Live:** [https://ualinuxoid.github.io](https://ualinuxoid.github.io)

## What’s here

- One-liner installers for Tor-as-VPN, WGuard, NoRU, Privacy hardener, Adblock, SSDShield, MAT2, media compress, yt-dlp GUI, first-time setup, WireGuard switcher
- Experimental tools (hosts blocker, GPG GUI, Duck email aliases, Windows data recovery, Reed–Solomon protector)
- Ukrainian / English UI, dark theme
- 🐱 Easter egg at [/cat/](https://ualinuxoid.github.io/cat/)

## Source of scripts
