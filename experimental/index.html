🧪 Experimental projects

Tools that need caution
⚠️ WARNING! Experimental section is NOT fully tested, and should NOT be used on critical installations! If you consider to use them, always make FULL backup before running anything from this section!
🛡️ Hosts file generator crapblock.sh
Blocks most popular .ru and .su domains via /etc/hosts.
🦊 Codeberg 🐙 GitHub
🔐 GPG GUI crypt.sh
Uses GPG, zenity and pure bash to create a lightweight and easy-to-use encryption solution for Linux Mint.
🦊 Codeberg 🐙 GitHub
📧 Email alias GUI aliaser.sh
Based on curl and zenity. You need an already registered @duck.com account to use it.
⚠️ WARNING! Aliaser is experimental, not tested carefully, and written at midnight. It should NOT be used as your only alias solution; fixes and bug reports are welcome though.
To use it, first register a @duck.com account, then install dependencies:
sudo apt update && sudo apt install curl jq zenity xclip
Aliaser logic was taken from this awesome project.
🦊 Codeberg 🐙 GitHub
💾 Windata windata.sh
Helps you extract your personal files from a Windows machine. Designed to run from a live Debian-based Linux. Experimental tool.
🦊 Codeberg 🐙 GitHub
📦 Reed–Solomon file protector reed-solomon.sh
Aims to help you not to lose or damage your data on partially faulty storage systems. In short — this will try to prevent data corruption.
⚠️ I am NOT a python developer! I respect my users and will NOT put this tool in the main section until it passes someone's review. USE AT YOUR OWN RISK.
