⚡ Lintweak

🇺🇦 Прості Linux-твіки, переважно написані на чистому bash.

Увага: GitHub використовується лише як дзеркало. Будь ласка, використовуйте Codeberg для будь-яких питань або внесків.

🧅 Tor installer
Встановлює Tor як «VPN» (весь системний трафік через Tor) для обходу цензури чи блокувань. Усі залежності та GUI керування встановлюються автоматично. Дружній до новачків.
Codeberg sudo curl -s https://codeberg.org/ualinuxoid/lintweak/raw/branch/main/scripts/tor.sh | bash
GitHub (дзеркало) sudo curl -s https://github.com/ualinuxoid/lintweak/raw/refs/heads/main/scripts/tor.sh | bash
🛡️ WGuard installer

🇬🇧 Simple Linux tweaks mainly written in pure bash.

Note: GitHub is used only as mirror. Please use Codeberg if you need to submit anything.

🧅 Tor installer
Installs Tor as a "VPN" (full system traffic passes through Tor) to bypass censorship or network restrictions. All dependencies and GUI control are managed automatically. Beginner-friendly.
Codeberg sudo curl -s https://codeberg.org/ualinuxoid/lintweak/raw/branch/main/scripts/tor.sh | bash
GitHub (mirror) sudo curl -s https://github.com/ualinuxoid/lintweak/raw/refs/heads/main/scripts/tor.sh | bash
🛡️ WGuard installer
Installs tweaks to hide your identity in wireless and wired networks, including (but not limited to) random MAC, fake OUI (manufacturer spoof), fake hostname, etc. Comes with a GUI, safe for beginners.
Codeberg sudo curl -s https://codeberg.org/ualinuxoid/lintweak/raw/branch/main/scripts/wguard.sh | bash
GitHub (mirror) sudo curl -s https://github.com/ualinuxoid/lintweak/raw/refs/heads/main/scripts/wguard.sh | bash
🚫 Advanced ru network blocker
Tries to block as much "runet" as possible. Supports three modes: normal (to hosts content), aggressive (fights ru TLDs) and extreme (uses IP banlist, not recommended).
Codeberg sudo curl -s https://codeberg.org/ualinuxoid/lintweak/raw/branch/main/scripts/noru.sh | bash
GitHub (mirror) sudo curl -s https://github.com/ualinuxoid/lintweak/raw/refs/heads/main/scripts/noru.sh | bash
🔒 Privacy hardener
