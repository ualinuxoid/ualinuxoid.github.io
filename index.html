⚡ Lintweak

🇺🇦 Прості Linux-твіки, переважно написані на чистому bash.

Увага: GitHub використовується лише як дзеркало. Будь ласка, дивіться оригінал на Codeberg.

🧅 Tor installer
Встановлює Tor як «VPN» (весь системний трафік через Tor) для обходу цензури чи блокувань. Усі залежності встановлюються автоматично.
Codeberg sudo curl -s https://codeberg.org/ualinuxoid/lintweak/raw/branch/main/scripts/tor.sh | bash
GitHub (дзеркало) sudo curl -s https://github.com/ualinuxoid/lintweak/raw/refs/heads/main/scripts/tor.sh | bash
🛡️ WGuard installer
Встановлює твіки для приховування особи в бездротових та дротових мережах: випадкова MAC-адреса, підміна OUI, тимчасовий hostname тощо.
Codeberg sudo curl -s https://codeberg.org/ualinuxoid/lintweak/raw/branch/main/scripts/wguard.sh | bash
GitHub (дзеркало) sudo curl -s https://github.com/ualinuxoid/lintweak/raw/refs/heads/main/scripts/wguard.sh | bash

🔒 Privacy hardener
