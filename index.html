🇺🇦 Прості Linux-твіки, переважно написані на чистому bash.

Увага: GitHub — лише дзеркало. Оригінал на Codeberg.

🧅Tor installer
Встановлює Tor як системний «VPN»: весь трафік іде через Tor. Підходить для обходу цензури. Залежності та GUI-керування ставить сам скрипт. Дружній до новачків.
Codebergsudo curl -s https://codeberg.org/ualinuxoid/lintweak/raw/branch/main/scripts/tor.sh | bash
GitHub (дзеркало)sudo curl -s https://github.com/ualinuxoid/lintweak/raw/refs/heads/main/scripts/tor.sh | bash
