⚡ Lintweak

🇺🇦 Прості Linux-твіки, переважно написані на чистому bash.

Увага: GitHub використовується лише як дзеркало. Оригінал — на Codeberg.

🧅 Tor installer
Встановлює Tor як «VPN» (весь системний трафік через Tor) для обходу цензури чи блокувань. Залежності встановлюються автоматично.
Codeberg sudo curl -s https://codeberg.org/ualinuxoid/lintweak/raw/branch/main/scripts/tor.sh | bash
GitHub (дзеркало) sudo curl -s https://github.com/ualinuxoid/lintweak/raw/refs/heads/main/scripts/tor.sh | bash
🛡️ WGuard installer
Твіки для приховування особи в мережах: випадкова MAC, підміна OUI, тимчасовий hostname тощо.
